# User Management

A small beginner-friendly Python project for practicing Git, GitHub and code review.
It stores users in memory and lets you add users, find them by ID and validate email addresses.

## Files

- `user_manager.py` - the functions (`add_user`, `find_user_by_id`, `validate_email`)
- `main.py` - a demo script that uses those functions

## Requirements

Python 3.8 or newer. No extra packages are needed.

## How to run

```
python main.py
```
